# NVO Endereço Fiscal

Landing page do serviço de Endereço Fiscal do NVO Coworking.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Vercel

## Desenvolvimento local

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Depois, abra `http://localhost:3000`.

## Build de produção

```bash
npm run build
npm run start
```

## Deploy

O projeto está estruturado para deploy direto na Vercel a partir deste repositório. Não há configuração específica de infraestrutura necessária neste estágio.
